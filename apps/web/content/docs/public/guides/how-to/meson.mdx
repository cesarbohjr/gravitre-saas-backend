**Meson** is Gravitre's brand name for the guided system builder. It helps you go from a plain-language goal to deployable agents, workflows, and training artifacts — with review before production.

Requires **Control** plan or above for full Meson API access.

## Where to find Meson

- **Agents** page → **Build with Meson** wizard
- **Settings → Meson Addons** for premium capabilities
- **Metrics** may show Meson-related insights when enabled

## Typical flow

1. Describe the system you want (team, tools, outcomes)
2. Review Meson's proposed agents, workflows, and training plan
3. Edit or reject pieces before deploy
4. Publish to your org or test in a non-production Environment

## API

Meson endpoints live under `/api/meson/*` (Control tier). See [OpenAPI](/docs/api/openapi.json).
