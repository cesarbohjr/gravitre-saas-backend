**Org Learning** covers the admin **Intelligence** area (`/admin/intelligence`) — org-wide learning, memory promotion, and quality evaluation.

## Who should use this

Org admins improving search quality, promoted team knowledge, and agent memory hygiene.

## Key tasks

- Review learning progress and outcome evaluations
- **Save to team knowledge** — promote vetted agent memories to shared org knowledge (formerly "memory promotion")
- Monitor search ranking status for admin diagnostics

## Public documentation boundary

This guide covers **what admins can do in the UI**. Internal ranking models, training pipelines, and algorithm details are documented only on the private internal docs site.

## API

Admin intelligence endpoints are under `/api/admin/intelligence/*` and require admin privileges.
