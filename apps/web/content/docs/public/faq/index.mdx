## Getting started

### Where do I start after sign-up?

Follow the [Quickstart](/docs/getting-started/quickstart), then connect one [Connector](/docs/guides/how-to/connectors) and run a [workflow](/docs/guides/how-to/workflows) or [Gravitre AI (Execute mode)](/docs/guides/how-to/ai-operator) task.

### What happened to Agent Swarm, Command Center, and Model Registry?

| Old name | New name | Canonical route |
|----------|----------|-----------------|
| Agent Swarm | **Multi-Agent Run** | `/multi-agent-run` |
| Command Center / AI Operator | **Gravitre AI (Execute)** | `/ai?mode=execute` |
| Workspace Chat | **Gravitre AI (Chat)** | `/ai?mode=chat` |
| Org Learning / Intelligence admin | **Learning (GIBE)** | `/intelligence/learning` |
| AI Models registry | **Models** | `/models` |
| Intelligence models catalog | **Built-in models** | `/models/built-in` |

Legacy `/agents/swarm`, `/operator`, `/command-center`, `/assistant`, and `/admin/intelligence` redirect permanently.

### Should I use Runs or Tasks?

Use **Runs** for workflow execution history. The **Tasks** page is legacy assignment UI — prefer Runs for automation audit trails.

## GIBE (Gravitre Intelligent Business Engine)

### What is GIBE?

**GIBE** is Gravitre's org-scoped learning engine — query clusters, memory promotion, built-in ML models, retrieval rankers, and predictive ops. It learns only from verified signals in your org and shows **TRAINED** / **data gate** status honestly.

See [GIBE — Learning](/docs/guides/how-to/org-learning).

### Where do I see GIBE in the app?

| Surface | Route |
|---------|-------|
| **Insights** | `/intelligence` |
| **Learning** (GIBE admin) | `/intelligence/learning` |
| **Built-in models** | `/models/built-in` |
| **Training** | `/training` |
| **Models** (production registry) | `/models` |

### Does GIBE auto-change my workflows?

No. GIBE recommendations, failure predictions, and memory promotions stay **advisory** until you review and apply them.

## Marketplace

### How do I install a workflow template?

Open [Install from the Marketplace](/docs/guides/how-to/marketplace), browse the catalog, connect required Connectors, then click **Install**.

### Can I share assets only inside my company?

Yes. Publish to **Your organization** and use the org publish queue — see [Publish Marketplace assets](/docs/guides/how-to/marketplace-publish).

## Schedules

### Where do I see upcoming cron runs?

Open **ACTIVITY → Schedules** for the org calendar, or a single workflow's **Schedules** tab. See [Manage schedules](/docs/guides/how-to/schedules).

### What's the difference between Schedules and Runs?

**Schedules** shows what is planned next (including projected cron occurrences). **Runs** shows execution history and outcomes after jobs start.

## Sources and training

### What's the difference between Sources and Connectors?

**Connectors** act on SaaS apps (OAuth). **Sources** connect databases and warehouses for queries and sync. See [Sources overview](/docs/concepts/sources).

### Where do I fine-tune an agent?

Use **Training** (`/training`) for datasets, jobs, and custom instructions. See [Use Training](/docs/guides/how-to/training).

### What is Models vs Training?

**Training** is for agent-focused fine-tunes and instructions. **Models** is the full production registry with deploy and predict APIs — requires **Command** plan. **Built-in models** (`/models/built-in`) is the GIBE ML catalog. See [Models overview](/docs/concepts/ai-models).

## Gravitre AI modes

Gravitre AI is one surface (`/ai`) with three modes:

| Mode | Route | Use when |
|------|-------|----------|
| **Execute** | `/ai?mode=execute` | Tracked work with plans and async jobs |
| **Chat** | `/ai?mode=chat` | Multi-turn Q&A, briefings, exploratory help |
| **Find** | `/ai?mode=find` or `/search` | Locate records and jump to them (links, not chat) |

Legacy `/chat` URLs redirect to `/search`.

### What's the difference between Execute, Chat, and Find?

In short: **execute** vs **converse** vs **find**. Full guides: [Execute mode](/docs/guides/how-to/ai-operator), [Chat mode](/docs/guides/how-to/assistant), [Universal Search](/docs/guides/how-to/search).

## Assignments and Goals

### Assignments vs Runs?

**Assignments** track delegated tasks with owners and due dates. **Runs** are workflow execution logs. See [Assignments](/docs/concepts/assignments).

### How do Goals become workflows?

Generate a plan on a goal, review connectors and approvals, then create or export a workflow. See [Define and track goals](/docs/guides/how-to/goals).

## Insights

### Metrics vs History?

**Metrics** shows trends and dashboards. **History** (`/audit`) shows individual audit events. See [Metrics](/docs/concepts/metrics) and [History](/docs/concepts/history).

### What are failure alerts?

**Failure predictions** (`/workflows/failure-predictions`) flag workflows at elevated failure risk — powered by GIBE when enough run history exists. See [Failure alerts](/docs/guides/how-to/failure-alerts).

## Lite and Enterprise

### What is Gravitre Lite?

A reduced console at `/lite` for Lite seat users. Allocate seats under **Settings → Lite Seats**. See [Gravitre Lite](/docs/concepts/gravitre-lite).

### Where are Enterprise controls?

**Settings → Enterprise** — integration health, data residency, white label, cost, SIEM export. See [Configure Enterprise](/docs/guides/how-to/enterprise).

### Settings vs Enterprise?

**Settings** covers all plans (SSO, API keys, team, webhooks). **Enterprise** adds compliance and scale controls on Enterprise plan. See [Manage settings](/docs/guides/how-to/settings).

## Execution and safety

### Will Gravitre always execute actions I describe?

Not without connected integrations and approvals where configured. Each run shows what was analyzed vs executed. Connectors must reach **Executable** status.

### Where do approvals appear?

**ACTIVITY → Approvals** and in run detail when a step requires human confirmation.

## Plans and billing

### What plan includes Meson?

**Control** and above. See [Build with Meson](/docs/guides/how-to/meson).

### What plan includes GIBE Learning admin?

**Control** and above. **Built-in models** and deeper predictive ops scale on **Command**.

### What plan includes Multi-Agent Run?

**Command** and above. See [Multi-Agent Run](/docs/guides/how-to/multi-agent-run).

### How do I upgrade after trial expiry?

**Settings → Billing** or the upgrade modal → Payment Element checkout. See [Plans and checkout](/docs/billing/plans-and-checkout).

## API

### Is there an official SDK?

Not yet. Use REST with [API quickstart](/docs/api/quickstart) and [OpenAPI](/docs/api/openapi.json).

### What is the API base URL?

`https://gravitre.app/api` — not `api.gravitre.app/v1`.

## Integrations

### Which connectors have setup guides?

Production-ready vendors listed on [Connect integrations](/docs/guides/how-to/connectors#production-ready-integration-guides).

### Where is Partner Connections?

**Settings → Federation** (`/settings/federation`) in the app; docs call this **Partner Connections**. Requires **Control** plan and admin role. See [overview](/docs/concepts/partner-connections) and [guide](/docs/guides/how-to/partner-connections).

### Can partners write to my CRM via connector grants?

No — federated **connector grants** allow **read-only** actions only. Writes stay inside each org's own connectors and approval policy.
