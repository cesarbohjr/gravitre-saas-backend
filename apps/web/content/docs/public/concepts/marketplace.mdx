The **Marketplace** is where teams discover, install, and manage reusable automation assets — without building everything from scratch.

## What you can install

| Asset type | What it gives you |
|------------|-------------------|
| **Agents** | Pre-configured AI workers with instructions and tools |
| **Workflows** | Ready-made automations you can customize |
| **Knowledge packs** | Curated context for search and agent use |
| **Department packs** | Bundled outcomes for Sales, Marketing, Support, Finance, and HR |

Assets may require specific **Connectors** before install. The catalog shows readiness (for example “2/3 apps connected”).

## Who it is for

- **Operators** — install vetted packs to move faster
- **Builders** — start from templates instead of blank workflows
- **Org admins** — publish internal assets, review install activity, manage private bundles
- **Partners / publishers** — submit connectors and paid assets (admin onboarding required)

## Public vs org-only assets

- **Browse catalog** — community and Gravitre-published assets
- **Your organization** — assets shared only inside your org
- **Installed** — assets already deployed to your workspace

## Partner connectors

The **Partner connectors** view lists federated partner registry entries in the same catalog shape as first-party Connectors. See [Partner Connections](/docs/guides/how-to/partner-connections) for cross-org collaboration.

## Plans

Browsing and installing many assets is available on paid plans. Publisher revenue, private bundles, and advanced analytics may require admin roles or higher tiers — details appear in-app when an action is restricted.
