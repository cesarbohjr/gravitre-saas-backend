Gravitre is an AI-assisted automation platform for teams that want to plan work in natural language, connect business tools, and run repeatable workflows with human oversight where it matters.

## Who Gravitre is for

- **Operations and RevOps** — sync CRM data, route approvals, schedule recurring jobs
- **Team leads** — assign work to AI agents and track outcomes in **Runs**
- **Builders** — design workflows, connect sources, and publish assets in the **Marketplace**
- **Enterprise admins** — SSO, residency, branding, integration health, and SIEM export

## How teams typically adopt Gravitre

```text
Week 1: Quickstart → one Connector → first Run
Week 2: Workflows or Marketplace templates → Approvals policy
Week 3: Command Center + Workspace Chat for daily ops → Metrics dashboards
Month 2+: Goals, Multi-Agent Run, Enterprise controls (as plan allows)
```

## Core concepts

| Concept | What it means |
|---------|----------------|
| **Command Center** | Work console for plans, async jobs, and monitored execution (`/operator`) |
| **Workspace Chat** | Multi-turn conversational help and org Q&A (`/assistant`) |
| **Universal Search** | Unified lookup across runs, workflows, agents, connectors, and documents (`/search`) |
| **Agents** | Configurable AI workers with tools and memory |
| **Workflows** | Visual automations with triggers, steps, and approvals |
| **Connectors** | OAuth and API integrations to external systems |
| **Sources** | Data connected for search, queries, and knowledge sync |
| **Marketplace** | Catalog of installable agents, workflows, knowledge, and department packs |
| **Training Hub** | Datasets, fine-tuning jobs, and custom instructions for agents |
| **AI Models** | Production model registry, deploy, and inference (Command plan) |
| **Schedules** | Calendar of upcoming workflow crons, tasks, and training jobs |
| **Runs** | History and status of workflow and agent executions |
| **Assignments** | Delegated work tracking for people and agents |
| **Goals** | Outcome-driven objectives with AI-generated workflow plans |
| **Metrics** | Operational dashboards for runs, workflows, and connector health |
| **History** | Audit log of org actions for security and compliance |
| **Gravitre Lite** | Simplified seat-based experience at `/lite` |
| **Enterprise** | Integration health, residency, white label, cost, and SIEM export |
| **Settings** | Org profile, security, API keys, webhooks, and billing |
| **Meson** | Gravitre's guided system builder for agents, workflows, and training from one request |

## Common use cases

- Sync new CRM records on a schedule and notify Slack on failure
- Route high-risk CRM writes through **Approvals** and **Expert Review** nodes
- Generate weekly reports from connected analytics tools
- Coordinate parallel agent work with **Multi-Agent Run** (Command plan)
- Publish approved workflow templates to your org via **Marketplace**
- Export audit logs to your SIEM (Enterprise **Security log export**)
