**Universal Search** (sidebar label; route `/search`) finds records across your organization without starting a chat thread. The legacy URL `/chat` redirects to `/search`.

## What Universal Search indexes

Results are grouped by entity type:

| Type | Examples |
|------|----------|
| **Workflow runs** | Failed runs, recent executions |
| **Workflows** | Definitions using a connector |
| **Agents** | Agent configs and roles |
| **Connectors** | Integration status |
| **Sources** | Connected databases and warehouses |
| **Documents** | Ingested knowledge files |

## Universal Search vs Workspace Chat vs Command Center

| **Universal Search** | **Workspace Chat** | **Command Center** |
|----------------------|--------------------|--------------------|
| Structured results with links | Natural-language answers in a thread | Action plans and tracked jobs |
| Best for known keywords | Best for exploratory dialogue | Best for delegated execution |
| `/search` | `/assistant` | `/command-center` |

Use Universal Search to locate an object; use Workspace Chat to interpret and recommend next steps; use Command Center to assign and monitor work.

## History

Search saves recent queries per user (`GET /api/search/history`) for quick replay.
