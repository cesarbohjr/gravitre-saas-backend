**Gravitre Lite** (`/lite`) is a streamlined product surface for organizations that need core automation and assistant capabilities without the full operator console.

## Lite vs full platform

| | **Gravitre Lite** | **Full platform** |
|---|-------------------|-------------------|
| **Navigation** | Reduced sidebar under `/lite/*` | Full WORK / BUILD / INSIGHTS sections |
| **Seats** | Lite seat licensing | Standard org seats |
| **API** | `/api/lite/*` scoped routes | Full `/api/*` surface |
| **Enterprise** | Limited; upgrade for Enterprise tabs | Full Enterprise settings |

Lite users may be redirected to Lite routes after login when their org assigns a Lite seat.

## Typical Lite capabilities

- Assistant-style chat within Lite home
- Curated workflows approved for Lite tenants
- Basic run visibility for assigned automation
- Org admin manages Lite seats under **Settings**

Exact feature flags depend on org configuration.
