Trigger and acknowledge incidents; integrate on-call workflows with Gravitre.

**Auth:** OAuth

## Setup

1. Connect **PagerDuty** from Connectors.
2. Configure inbound webhooks in PagerDuty pointing to Gravitre if using event triggers.

See [Webhooks](/docs/api/webhooks) for inbound URL patterns.
