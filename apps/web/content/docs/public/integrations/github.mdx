Manage repositories, issues, and pull requests via GitHub tools.

**Auth:** OAuth or personal access token

## Setup

1. Choose OAuth or PAT when adding the connector.
2. Scope tokens to minimum required repositories.
3. Test read-only actions before enabling write tools.
