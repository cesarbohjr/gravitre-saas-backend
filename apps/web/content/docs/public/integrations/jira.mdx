Create and search Jira issues from automated workflows.

**Auth:** OAuth (Atlassian cloud)

## Setup

1. Connect **Jira** and pick your Atlassian cloud site.
2. Grant the connector access to required projects.
3. Add Jira steps in the workflow builder.
