ERP read/write via Odoo JSON-RPC API key authentication.

**Auth:** API key

## Setup

1. Generate an API key in Odoo user preferences.
2. In Gravitre, add **Odoo** with URL, database, username, and API key.
3. Test read tools before enabling writes.
