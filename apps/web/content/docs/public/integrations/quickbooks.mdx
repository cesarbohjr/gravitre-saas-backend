Read financial objects and run QuickBooks actions when connected.

**Auth:** OAuth (Intuit)

## Setup

1. Connect via **Connectors → QuickBooks**.
2. Select the correct QuickBooks company during OAuth.
3. Test with a dry-run workflow before write actions.
