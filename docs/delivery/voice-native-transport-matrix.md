# Native transport matrix (isolated)
Nine configurations: 10/20/40ms native output chunks crossed with browser default, 0ms and 40ms requested jitterBufferTarget. Twenty independent loopback repetitions per configuration. Original reference workflow retained. No custom DSP or provider activation. Output ingress/write and interruption entry/exit are observed without manipulating SDK queues. Exact frame-ID residence is reported only when identity survives native rechunking; unmatched frames are unknown. Pending ingress bookkeeping is NOT queue depth and does not prove clearing. Browser cumulative jitterBufferDelay divided by emitted count is a session-average, not interruption-specific residence. Targets are hints, not measured achieved delay. Existing gap, completion and onset bounds retained; matrix requires strictly below 300ms residual. No promotion or real-device claims. Parallel runners introduce environment variation; results screen candidates only.
