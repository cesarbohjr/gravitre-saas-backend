# v0 visual handoff prompt (post–IA consolidation)

Use only after functional IA verification (nav counts, redirects, link check, chat battery).

## Context

Gravitre admin IA is consolidated to ~14 primary sidebar destinations. Hubs:

- **Activity** (`/activity`) — BusinessOutcome list + Failures tab
- **Agents** (`/agents`) — Roster · Multi-agent · Training tabs
- **Intelligence** (`/intelligence`) — operational health, ROI, learning, models, memory, predictive
- **Settings** (`/settings`) — Personal · Organization · Admin tiers

Do **not** invent new top-level nav items. Visual redesign only.

## Prompt for v0

> Redesign the Gravitre admin shell around four hubs already in the product: Activity, Agents, Intelligence, and Settings. Keep the primary sidebar at about 14 items (Home, Chat, Agents, Assignments, Goals, Marketplace, Workflows, Connectors, Sources, Activity, Schedules, Approvals, Intelligence, Settings). Activity should feel like an execution timeline with an All / Failures tab switcher. Agents should show Roster / Multi-agent / Training as in-hub tabs. Intelligence is a section grid into operational health, ROI, learning, models, and memory. Settings uses Personal / Organization / Admin progressive disclosure. Preserve clarity and density for operators; no purple dashboard clichés; no new marketing chrome on app surfaces.
