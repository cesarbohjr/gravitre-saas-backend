# Voice architecture paired screening contract

Status: proposed reference-only. Both candidates must execute identical workload IDs and repeats, with exact source SHA, fixture digest, provider/model/SDK versions and environment identity. Keep transport-only synthetic audio and protocol-only text separate from live conversational evidence. A missing acoustic metric is NOT RUN, never zero. Record same-clock microphone onset/end, committed turn, first text, first audible audio, interrupt request, last old audible audio, subsequent first audio and completion. Record gap duration, RTP loss when applicable, response identity, errors, cancellation and unauthorized effects. Compare nearest-rank p50/p95 and failure rates only across complete matched cohorts, minimum 20 paired trials per workload for screening. No subjective parity certification without blinded speech assessment and real device evidence.

Progressive One Brain: R0 tool-free; R1 canonical model routing; R2 conversation context; R3 retrieval; R4 governance; R5 governed actions. Provider owns speech lifecycle; Gravitre owns committed business intent, generation fence, authenticated tenant identity and durable execution. Never expose provider transcript or session ID as action authority. Each stage must retain cancellation and durable outcome tests and compare against previous stage. No production route or paid provider activation. SQLite bindings in reference are a local test mechanism, not production multi-instance authorization.
