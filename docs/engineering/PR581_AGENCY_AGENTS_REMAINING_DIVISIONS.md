# Agency Agents — remaining divisions inventory (PR #581)

**Status:** research inventory and **proposed** classification only; no runtime roles, packages, dependencies or marketplace seeds added. Source: [Agency Agents upstream README](https://github.com/msitarzewski/agency-agents/blob/main/README.md), README blob SHA `5c59c078e3388ec5af5b134ff2137aca42cd7555`, retrieved 2026-10-27. The README is a changing index; before code import pin the upstream commit and verify each linked agent file and license. This document covers all non-engineering divisions visible in that README, not a guaranteed complete filesystem census.

**Scope:** 217 linked non-engineering profiles across 17 divisions; classification: 14 default candidates, 192 marketplace candidates, 11 gated review. Existing engineering tranche is in [PR581_AGENCY_AGENTS_CATALOG_CLASSIFICATION.md](PR581_AGENCY_AGENTS_CATALOG_CLASSIFICATION.md). Categories are not install status and are not final product decisions.

**Classification rule:** Default means a candidate for a generally useful, existing Gravitre agent capability (not necessarily a new selectable agent). Marketplace means opt-in `ai_agent` or `department_pack` via the existing catalog, with connector readiness and entitlement checks. Review/gated means sensitive domain or elevated-action workflows must undergo security, legal and policy review before publishing; no autonomous financial, medical or offensive-security actions. Names are heuristically classified and need human curation and existing catalog collision analysis.
