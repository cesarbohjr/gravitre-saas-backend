## Behavior and safeguards

Every destination has bounded role guidance, provenance-checked immutable references, a canonical advisory software-review workflow and prioritized supported connector guidance. All new agents have zero default systems/tool grants. Existing IT triage retains its department, identity and grant count. All agents can install and review supplied evidence offline; live actions still pass existing tenant/IAM, account, quota, approval and cancellation controls. No new connector, price, badge, model-quality claim or automatic installation is introduced. Connector names in upstream specialties are expertise descriptions, not claims that Gravitre supports those integrations.

The canonical seed service publishes new immutable snapshots for the affected agents. Upgrade and rollback preserve identity and leave baseline snapshots unchanged. Publication cannot be bypassed using force. Role-specific guidance appears identically in the shared full and compact/text/voice prompts. Hardware, embedded firmware, physical repair, physical networking and equipment work are explicitly outside the runtime guidance.
