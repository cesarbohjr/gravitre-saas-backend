## Visual rules (product)

**Avoid:** Card-first, card-in-card, tab-first IA, decorative badges, giant avatars, floating icon grids, hover glow spam, permanent multi-panels, different language per route.

**Use:** Nodus type/composition · `#16a374` · semantic color · Nucleo · contextual inspectors · topology · execution traces · direct manipulation · progressive disclosure · real evidence · state-driven motion.

Alive because **work is happening**, not because the page is constantly moving.
