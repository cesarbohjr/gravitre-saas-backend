# GRAVITRE_UX_RULES.md

**Authority:** Subordinate to `GRAVITRE_3_0_PLUS_MASTER_SPEC.md` (§§3–5, 13, 23–24, 31–32, 47).  
**Phase:** 5 consolidation.

## Operating loop

Ask → Understand → Plan → Visualize → Modify → Approve → Execute → Observe → Learn

## Interaction layers (§5)

1. **Intent** — Ask, voice, search/command, contextual AI, direct create, page prompts.  
2. **Adaptive workspace** — Render from approved component registry only (no arbitrary CSS/UI).  
3. **Expert workspace** — Builder, graphs, Model Studio, connectors, governance — AI augments, does not delete.

## Protection (§4)

Do not discard Workflow Builder, graphs, Intelligence expert views, Model Studio, connectors, approvals, governance, execution monitoring because chat can initiate the same task.

## AI state vocabulary (§13)

Canonical labels must map to runtime: Planning, Waiting, Running, Tool activity, Approval required, Paused, Completed, Failed, Cancelled.  
Never fabricate progress %, confidence, completion, reasoning, or tool activity. Never expose hidden chain-of-thought.

## Progressive forms (§23)

Fewest steps necessary; Back/Next; preserved state; inline validation; good defaults; review before consequential actions.

## Surface grammar (§24)

Popover · Drawer/inspector · Modal · Dedicated page · Floating window · Fullscreen — use by task size; preserve state across related surfaces.

## Shared actions (§31)

Create / Edit / Save / Publish / Run / Approve / Reject / Cancel / Delete / Filter / Select / Inspect / Expand / Minimize / Retry / Back / Undo — consistent behaviour product-wide.

## Honesty

No invented customer prices, badges, Enable toggles, or fake confidence. Screenshots ≠ completion (§46).
