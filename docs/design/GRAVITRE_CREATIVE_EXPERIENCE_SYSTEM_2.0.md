## B. Updated creative direction

**1.0:** Quiet Nodus + illustrative intelligence storytelling (phase machines).  
**2.0:** Same restraint + **meaningful visitor agency** so someone can SEE, EXPLORE, and UNDERSTAND:

1. How information becomes knowledge  
2. How knowledge enables agents  
3. How agents coordinate work  
4. How governance controls execution  
5. How evidence verifies results  
6. How outcomes inform learning  

**Design principle:** Minimum interface for maximum capability.  
**Creative principle:** A quiet interface surrounding a living intelligence system.  
**Interaction principle:** Complexity appears when requested — default view stays quiet.

## D. Interaction grammar

| Verb | Purpose | Default availability |
|------|---------|----------------------|
| HOVER | Preview highlight only — never sole meaning | Desktop |
| FOCUS | Keyboard-equivalent of hover | Always |
| SELECT | Commit object into inspect rail | Layer 2 |
| INSPECT | Show evidence / why / honesty for selection | Layer 2 |
| TRACE | Emphasize path through selected objects | Layer 2 |
| STEP | Advance one narrative beat (visitor-owned) | Layer 3 |
| SCRUB | Drag timeline of beats (optional; pause required) | Layer 3 rare |
| COMPARE | Side-by-side match vs reject / success vs failure | Layer 3 |
| RESOLVE | Show terminal verified composition | Always |
| REPLAY | Restart illustrative scenario | Layer 3 |
| RESET | Clear selection; return to quiet Layer 1 | Always |

Do not ship all verbs on every scene.

## E. State-driven motion

One dominant narrative motion at a time. Allowed semantic motions:

Receiving · Normalizing · Matching · Rejecting · Delegating · Executing · Verifying · Learning · Resolving · Waiting (amber)

Forbidden as primary: continuous orbit, parallax decoration, multi-loop competing timers.

Reduced motion: final composition + captions; disable transform autoplay (Motion `reducedMotion="user"` + scene `shouldAnimate`).

## Knowledge Fabric enhancement concepts (for review — do not implement)

### KF-A — Entity Convergence Workbench (**recommended**)

Visitor selects mentions from illustrative CRM/email sources. Raw vs normalized exposed. Exact-match path visible. Acme converges; Sarah / Sarah Smith stay apart. Evidence attaches. Teaches **why**.

- Desktop: workbench with source list + canvas + inspect  
- Mobile: stacked select → result  
- Interaction: SELECT, COMPARE, STEP, INSPECT  
- Motion: normalize pathLength; converge spring once  
- Reduced: static before/after panels  
- Engine: SVG+DOM+FM  
- Risk: low if honesty preserved  
- Why better: agency reveals match logic vs watching chips light  

### KF-B — Knowledge Fabric Lens

Same objects; visitor switches MENTIONS / NORMALIZED / RESOLVED / EVIDENCE. Reorganize in place.

- Teaches structure layers  
- Risk: mode tabs can feel product-UI; keep illustrative  
- Engine: DOM layout morph (opacity under reduced motion)  

### KF-C — Before / After Resolution

Fragmented mentions vs resolved identity; controlled transition; inspect match decisions.

- Strong editorial clarity  
- Risk: oversimplifies to slide deck  
- Engine: SVG crossfade + STEP  

**Recommendation:** **KF-A** — highest comprehension of exact-match truth with least risk of fake product demo.
